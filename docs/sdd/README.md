# Software Design Documents (SDD)

Bienvenido a la carpeta de **SDD**. Aquí es donde centralizaremos el proceso de **Schema-Driven Development** (o Software Design Documents).

## 🚀 Proceso Sugerido
1.  **Copia el `template.md`** y renómbralo según la funcionalidad (ej: `01-user-auth.md`).
2.  **Completa el diseño** describiendo los cambios en el frontend, backend y base de datos.
3.  **Usa este archivo** como referencia para que la IA (o tú mismo) implemente los cambios de manera estructurada.

## 📁 Estructura
- `template.md`: El punto de partida para nuevos diseños.
- `[nombre-de-funcionalidad].md`: Documentos específicos de cada desarrollo.

---
*Este espacio está diseñado para asegurar que el código siga una arquitectura sólida antes de ser implementado.*
